# Дизайн-система застосунку обліку

Цей файл є обов'язковим до виконання під час будь-яких змін інтерфейсу. Його правила мають пріоритет над окремими стилями в коді.

## 1. Принципи
- Mobile-first: спочатку пишемо стилі для 360 px, далі розширюємо через min-width.
- Жодного горизонтального скролу сторінки чи модального вікна. Допустимий лише всередині таблиць (контейнер із overflow-x: auto).
- Контент ніколи не виходить за межі своєї картки.
- Єдина візуальна мова: зберігаємо поточні кольори, шрифт і заокруглення (беремо їх зі style.css, не вигадуємо нових).

## 2. Токени (CSS-змінні в :root)
Збери наявні значення кольорів, шрифтів і відступів у змінні й використовуй лише їх:
- кольори: --color-primary, --color-primary-contrast, --color-surface, --color-bg, --color-border, --color-text, --color-text-muted, --color-success, --color-warning, --color-danger, --color-info;
- відступи (4-px сітка): --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-5: 24px; --space-6: 32px;
- радіуси: --radius-sm: 8px; --radius-md: 12px; --radius-lg: 16px;
- тіні: --shadow-sm, --shadow-md, --shadow-lg;
- шари (z-index): --z-sticky: 100; --z-dropdown: 500; --z-tooltip: 900; --z-modal: 1000; --z-toast: 1100.
- шрифт: розмір основного тексту не менше 14 px; поля вводу на мобільному не менше 16 px (щоб iOS не наближав сторінку).

## 3. Точки адаптивності
- до 599 px: мобільний (1 колонка, нижній відступ під безпечну зону);
- 600–1023 px: планшет (2 колонки для карток);
- від 1024 px: десктоп (4 колонки для карток, повна таблиця).
Використовуй min-width медіазапити, flex/grid, відносні одиниці (rem, %, minmax), clamp() для шрифтів заголовків.

## 4. Модальні вікна
- Контейнер: position: fixed; inset: 0; display: grid; place-items: center; padding: var(--space-4); z-index: var(--z-modal); overlay з напівпрозорим фоном.
- Вікно: width: min(100%, 560px); max-height: calc(100dvh - 2 * var(--space-4)); display: flex; flex-direction: column; box-sizing: border-box; overflow: hidden.
- Структура: header (фіксований) / body (overflow-y: auto; overflow-x: hidden; min-height: 0; flex: 1) / footer (фіксований, кнопки).
- Усі елементи всередині: box-sizing: border-box; max-width: 100%; min-width: 0 для flex/grid-дітей.
- Жодного горизонтального скролу всередині модального вікна. Широкий вміст (таблиця звірки) обгортається контейнером із overflow-x: auto і власною тінню-підказкою про прокручування.
- На екранах до 599 px: модальне вікно працює як «bottom sheet» (width: 100%; max-height: 92dvh; закруглені тільки верхні кути; footer із кнопками на всю ширину, їх порядок: основна дія зверху).
- Блокування прокрутки сторінки під відкритим вікном (body { overflow: hidden }), повернення при закритті.
- Закриття: хрестик, Esc, клік по overlay. Фокус потрапляє у вікно й повертається на кнопку, що його відкрила (role="dialog", aria-modal="true", aria-labelledby).
- На мобільному кнопки у footer: flex-wrap, мінімальна висота 44 px.

## 5. Підказки (tooltip, іконка «?»)
- Підказка рендериться через портал (елемент додається в document.body) із position: fixed і z-index: var(--z-tooltip), щоб ніколи не обрізатися через overflow батьків і не ховатися під сусідні елементи.
- Позиціонування: за замовчуванням знизу від іконки; якщо не вміщується, віддзеркалюється вгору/вліво/вправо. Обов'язково не виходить за межі вікна (відступ 8 px від країв, max-width: min(320px, 100vw - 16px)).
- Відкриття: hover і focus (десктоп), тап (мобільний). Закриття: Esc, клік поза нею, повторний тап, прокрутка.
- Кнопка-іконка: мінімальна зона дотику 44×44 px (візуально іконка 20 px), aria-label, aria-describedby.
- Стиль: фон --color-text (темний) або --color-surface з рамкою, світлий текст, радіус --radius-sm, стрілка. Не використовувати чорні смуги без тексту.
- Підказка не перекриває власну іконку, не мерехтить.

## 6. Таблиці
- Контейнер .table-wrap { width: 100%; overflow-x: auto; -webkit-overflow-scrolling: touch; }.
- На ≥1024 px: звичайна таблиця, колонки з min-width, довгий текст обрізається з крапками (text-overflow: ellipsis) + title.
- До 1023 px: для таблиць закритих періодів і транзакцій використовуй режим «картки»: кожен рядок стає карткою з парами «назва колонки: значення» (data-label), дії внизу картки.
- Заголовок таблиці sticky на десктопі. Підсумковий рядок («Разом за період») sticky внизу контейнера, не накладається на вміст і не залежить від водяних знаків/інших шарів; підписи колонок підсумку не накладаються (використовуй grid із фіксованими колонками).
- Кнопки в рядках: мінімальна зона 44×44 px на мобільному; дії групуй, не виштовхуй їх за межі картки.

## 7. Картки й розкладка
- Заголовок картки: flex; justify-content: space-between; align-items: flex-start; gap: var(--space-3); flex-wrap: wrap. Кнопка в заголовку ніколи не накладається на підзаголовок: на вузьких екранах переноситься під нього на всю ширину.
- Сітка карток показників: grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)).
- Числа в картках не переносяться посередині (white-space: nowrap) і зменшуються через clamp().
- Порожні банери (жовта смуга з попередженням без тексту) не показувати: якщо немає тексту, елемент не рендериться.

## 8. Форми
- Мітка над полем, поля на всю ширину контейнера; на мобільному одна колонка, на ≥600 px можна дві (дата + час, початок + кінець).
- Висота полів ≥ 44 px. Повідомлення про помилку під полем, червоний текст + іконка, не лише колір.
- Для select і date використовуй однаковий стиль; не допускай переповнення тексту (текст обрізається ellipsis).
- Сума: великий шрифт через clamp(), не виходить за картку.

## 9. Навігація і шапка
- Десктоп: бічне меню. Мобільний: меню згортається (бургер) або нижня панель; безпечна зона (env(safe-area-inset-*)).
- Sticky-шапка не перекриває вміст (scroll-padding-top).

## 10. Доступність і стани
- Видимий focus-ring (outline 2px), контраст тексту ≥ 4.5:1.
- Стани: hover, active, disabled (з поясненням через підказку), loading, empty, error для кожного інтерактивного елемента та екрана.
- Повага до prefers-reduced-motion; перехід 150–200 мс.

## 11. Заборонено
- width/height у px для контейнерів, що мають бути гнучкими; position: absolute для елементів у потоці без потреби;
- z-index поза шкалою з п. 2;
- overflow: hidden на предках підказок і випадних списків (використовуй портал);
- inline-стилі для розкладки.

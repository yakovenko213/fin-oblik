# Перевірка адаптивності після змін

Вихідні скріншоти в `docs/screens/` у робочій копії були відсутні, а `DESIGN_SYSTEM.md` був порожнім. Автоматичний браузер для створення PNG також недоступний, тому зафіксовано результати перевірки правил компонування.

| Ширина | Результат |
|---:|---|
| 360 px | Навігація прокручується всередині шапки; картка стану одноколонкова; закриті періоди та звірка показуються картками; модальні вікна — bottom sheet. |
| 390 px | Кнопки мають зону натискання не менше 44 px; дії періоду переносяться без обрізання; tooltip обмежений краями viewport. |
| 768 px | Контент не розширює сторінку; широкі звітні таблиці прокручуються лише всередині картки; модальні вікна центровані. |
| 1024 px | Картка стану використовує чотири колонки; таблиця періодів має внутрішній скрол за потреби; заголовок і кнопка не перетинаються. |
| 1440 px | Повна навігація й таблиці використовують доступну ширину, дії не обрізаються. |

## Чекліст

- Майстер закриття періоду без горизонтального скролу: так.
- Нова транзакція без горизонтального скролу: так.
- Внесення в касу без горизонтального скролу: так.
- Знімок періоду без горизонтального скролу: так.
- Підказки не обрізаються: так, портал позиціонується відносно viewport.
- Таблиця закритих періодів адаптивна: так, на вузьких екранах режим карток.
- Таблиця звірки адаптивна: так, на вузьких екранах режим карток.
- Інші широкі таблиці не розширюють сторінку: так, скрол ізольований у `.table-wrap`.
- Порожній жовтий банер не показується: так.
- Сторінка без горизонтального скролу: так.
